## XDR5450 射频策略失效

| **设备型号** | **角色**  | **硬件版本** | **软件版本**                  |
| ------------ | --------- | ------------ | ----------------------------- |
| **AC100**    | AC 控制器 | 4.0          | 1.4.3 Build 240715 Rel.80898n |
| **XDR 5450** | AP 模式   | 3.0          | 1.0.1 Build 230221 Rel.60627  |

- **现象 1：手动调整 5G 信道和频宽不生效**
- **现象 2：5G 射频关闭后无法重新开启**
- **现象 3：无法获取实际运行的信道信息**

只有自动化“射频调优”能让设置生效；而**手动调整** 5G 射频设置（信道/频宽）或开关射频，网页端虽然显示已调整，但实际底层并未成功下发或应用到 AP 上。

将 XDR5450 升级至最新固件：**1.0.3 Build 250211 Rel.56826**。

- **可以正常获取实际运行信道信息**
- **手动调整 5G 信道和频宽不生效**
- **5G 射频关闭后无法重新开启**
