## 端口协商速率

```sh
printf "\033[1;36m%-10s | %-20s\033[0m\n" "端口 (Port)" "链路状态 (Link Status)"; \
echo "----------------------------------------"; \
for i in $(seq 1 5); do \
    status=$(swconfig dev switch0 port $i get link); \
    if echo "$status" | grep -q "up"; then \
        # 如果是 up，显示为绿色
        printf "Port %-5d | \033[1;32m%-20s\033[0m\n" "$i" "$status"; \
    else \
        # 如果是 down 或其他，显示为红色
        printf "Port %-5d | \033[1;31m%-20s\033[0m\n" "$i" "$status"; \
    fi \
done

端口 (Port) | 链路状态 (Link Status)
----------------------------------------
Port 1     | port:1 link:up speed:100baseT full-duplex txflow rxflow auto
Port 2     | port:2 link:down    
Port 3     | port:3 link:down    
Port 4     | port:4 link:down    
Port 5     | port:5 link:up speed:100baseT full-duplex auto
```
